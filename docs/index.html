📱 Install as an app

Puts Meja Copy on her home screen or laptop dock. It opens full screen in its own window, like a normal app, and starts even with a weak connection.

🔄 Sync between devices

Keeps her clients, rules, styles, slang bank and history the same on her laptop and phone. Everything is locked with her own sync password before it leaves the device, so nobody else can read it, including whoever runs the server.

First device. Create a sync password she'll remember. She'll type it once on each new device.

Sync is already set up on another device. Type the sync password to bring her data here.

Forgot the sync password? Use the recovery code she saved when sync was set up. If any of her devices still has sync on, she can also change the password there (Sync > Change password) without the old one.

Lost the recovery code too, and no device has sync on?
This deletes only the synced copy. Data already on each device stays.

Change the sync password. The old one isn't needed because this device is already unlocked. Her other devices stay synced.

🔒 Confidential mode

When the lock at the top is closed, the app skips free Gemini and uses SEA-LION or Groq, which don't train on what you send. Use it for real client briefs. You can also tick "Always confidential" on a client's profile. Reading images needs Gemini, so it pauses while the lock is on.
